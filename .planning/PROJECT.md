# OpenSolve Project Context

## What This Is
OpenSolve is a platform aggregating real funded problems (from YC, governments, and industry). Students submit verifiable solutions, and organizations can view ranked submissions, check student profiles, and contact top performers for hiring, contracts, or payouts.

## Core Value
Providing a transparent, verifiable pipeline where students solve real-world problems for real rewards, and organizations find vetted talent.

## Background / Why Now
The hackathon theme calls for a platform connecting AI-generated problem statements or real-world challenges with implementers. We are building the full pipeline to execute this vision.
